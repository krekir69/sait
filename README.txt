Лабораторная работа №5. DOM и взаимодействие с элементами страницы 
Цель: Научиться манипулировать DOM деревом, находить элементы, изменять 
содержимое и стили, а также сохранять состояние страницы между перезагрузками через 
localStorage.  
Задание: 
Реализовать интерактивные функции: 
 Поиск элементов через getElementById, querySelector, querySelectorAll. 
 Манипуляции с DOM: изменение текста, атрибутов, классов; добавление/удаление 
элементов. 
 Переключение темы (светлая/тёмная) по кнопке. 
 Скрытие/показ блоков по клику. 
 Обработка ошибок: проверка существования элемента. 
 Сохранение состояния в localStorage: при добавлении/удалении элементов и 
переключении темы сохранять данные; при загрузке страницы восстанавливать их.

Вариант 8. Тема «Кулинар и фуд-блогер» (список рецептов с ингредиентами) 
Контент: карточки рецептов (название, список ингредиентов в <ul>, кнопка «Удалить»). 
Логика: «Добавить рецепт» запрашивает название и ингредиенты (через несколько prompt 
или ввод через запятую), создаёт карточку и список. Кнопка «Удалить последний» 
убирает последнюю карточку. Переключение темы, скрытие блока рецептов. Проверка 
элементов.
